# Natural Language Processing assignments
This collection of assignments was developed for the NLP course, part of the Computer Science Master's degree at the University of Padua (A.Y. 2025-2026).

## Contents

The set of assignments aims to explore different concepts of NLP, in particular:
- Text preprocessing and sentiment analysis 
- Pre-trained word embeddings and training our own words embeddings
- Natural Language Generation (by building bigram and trigram models) and typo detection
- Named Entity Recognition comparing different approaches using BERT and Llama
- Build a simple and complete Retrieval-Augmented Generation (RAG) workflow
