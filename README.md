# Natural Language Processing assignments
This collection of assignments was developed for the NLP course, part of the Computer Science Master's degree at the University of Padua (A.Y. 2025-2026).

## Contents

The set of assignments aims to explore different concepts of NLP, in particular:
- Text preprocessing and sentiment analysis ([link] (/Lab_1_Preprocessing.ipynb))
- Pre-trained word embeddings and training our own words embeddings ([link] (/Lab_2_Word_Embeddings.ipynb))
- Natural Language Generation (by building bigram and trigram models) and typo detection ([link] (/Lab_3_Generation.ipynb))
- Named Entity Recognition comparing different approaches using BERT and Llama ([link] (/Lab_4_NER.ipynb))
- Build a simple and complete Retrieval-Augmented Generation (RAG) workflow ([link] (/Lab_5_RAG.ipynb))
